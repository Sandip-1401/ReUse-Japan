# ReUse Japan — DATABASE SCHEMA & DOCUMENTATION

> **Rule:** This document only reflects the *current actual* database state. Never document speculative or planned tables as existing tables.

---

## 1. Database Engine & ORM
- **Engine:** PostgreSQL 16/17 (Neon Serverless PostgreSQL, Region: Asia Tokyo `ap-northeast-1`)
- **Driver:** `@neondatabase/serverless` (HTTP / WebSocket connectionless serverless driver)
- **ORM:** Drizzle ORM (`drizzle-orm`, CLI: `drizzle-kit`)
- **Current Status:** Connected & Synced (Schema pushed via `drizzle-kit push`).

---

## 2. Existing Tables

### A. `user` Table
Primary user identity and profile data supporting the Unified Single Account model.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | text | PRIMARY KEY | Unique user identifier generated by Better Auth |
| `name` | text | NOT NULL | User's display name |
| `email` | text | NOT NULL, UNIQUE | User's login email address |
| `email_verified` | boolean | NOT NULL, DEFAULT false | Whether email has been verified via token |
| `image` | text | NULL | User avatar image URL |
| `role` | text | NOT NULL, DEFAULT 'user' | Platform role: `'user'` (buys & sells) or `'admin'` |
| `phone` | text | NULL | Japan phone number (e.g. `080-1234-5678`), progressive profiling |
| `postal_code` | text | NULL | Japan postal code (e.g. `150-0001` / 〒), progressive profiling |
| `prefecture` | text | NULL | Japan prefecture (e.g. `Tokyo`, `Osaka`), progressive profiling |
| `city` | text | NULL | Municipality/City (e.g. `Shibuya-ku`), progressive profiling |
| `address_line` | text | NULL | Street address and building details, progressive profiling |
| `created_at` | timestamp | NOT NULL, DEFAULT now() | Account creation timestamp |
| `updated_at` | timestamp | NOT NULL, DEFAULT now() | Account last updated timestamp |

---

### B. `session` Table
Active user sessions issued upon successful sign-in.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | text | PRIMARY KEY | Unique session identifier |
| `user_id` | text | NOT NULL, REFERENCES `user(id)` ON DELETE CASCADE | Associated user account |
| `token` | text | NOT NULL, UNIQUE | Secure session token sent via HttpOnly cookie |
| `expires_at` | timestamp | NOT NULL | Expiration timestamp of the session |
| `ip_address` | text | NULL | Client IP address for security logging |
| `user_agent` | text | NULL | Client browser/device user agent |
| `created_at` | timestamp | NOT NULL, DEFAULT now() | Session creation timestamp |
| `updated_at` | timestamp | NOT NULL, DEFAULT now() | Session last refreshed timestamp |

---

### C. `account` Table
Authentication credentials and OAuth linkage.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | text | PRIMARY KEY | Unique account record identifier |
| `user_id` | text | NOT NULL, REFERENCES `user(id)` ON DELETE CASCADE | Associated user account |
| `account_id` | text | NOT NULL | Provider-specific account ID (or user ID for credentials) |
| `provider_id` | text | NOT NULL | Provider name: `'credential'` (email/password) or `'google'` |
| `password` | text | NULL | Securely hashed password (only present for `'credential'` provider) |
| `access_token` | text | NULL | OAuth access token |
| `refresh_token` | text | NULL | OAuth refresh token |
| `id_token` | text | NULL | OAuth OpenID Connect token |
| `access_token_expires_at` | timestamp | NULL | Expiration of OAuth access token |
| `refresh_token_expires_at` | timestamp | NULL | Expiration of OAuth refresh token |
| `scope` | text | NULL | Granted OAuth permissions scope |
| `created_at` | timestamp | NOT NULL, DEFAULT now() | Account creation timestamp |
| `updated_at` | timestamp | NOT NULL, DEFAULT now() | Account last updated timestamp |

---

### D. `verification` Table
Temporary verification tokens for email confirmation and password resets.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | text | PRIMARY KEY | Unique token record identifier |
| `identifier` | text | NOT NULL | Identifier (e.g. user email address) |
| `value` | text | NOT NULL | Cryptographic token value |
| `expires_at` | timestamp | NOT NULL | Token expiration timestamp |
| `created_at` | timestamp | NOT NULL, DEFAULT now() | Token creation timestamp |
| `updated_at` | timestamp | NOT NULL, DEFAULT now() | Token last updated timestamp |
